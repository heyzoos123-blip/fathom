we have no way to see how language models think.

every benchmark on earth measures what comes out. accuracy, fluency, human preference. nobody measures what happens inside — which layers fire, which circuits activate, whether the model retrieved a cached answer or actually reasoned through the problem. we built the instrument that does.

the finding

when a transformer retrieves a memorized fact — "the capital of France is" — feature activation concentrates at output-proximal layers. the model knows the answer. it reaches for it directly. computation is shallow.

when a transformer reasons through an explanation — "why do economies experience inflation during monetary expansion" — feature activation distributes across mid-layer computation. the model does not know the answer. it builds it. computation is deeper and structurally distinct.

we tested this on 56 matched prompt pairs across three experimental phases. the core replication: 30 pre-registered, vocabulary-controlled pairs. every surface prompt and its paired insight prompt use matched word frequency, readability, n-gram overlap, and lexical diversity. the distinction is invisible to text statistics. it only exists inside the computational graph.

the decomposability law

the most important finding from the march 29 experiments: fathom depth is inversely proportional to the decomposability of the causal model in the response.

two responses to the same question with identical factual accuracy produce different depth scores based solely on whether the information is organized as independent modular components or as an interdependent causal web.

if answer = A₁ + A₂ + A₃ (independent parts) → depth ≈ 0
if answer requires A₁ × A₂ × A₃ (all together) → depth ≈ 0.4+

this is not a proxy for "answer quality." a step-by-step algebra solution that is perfectly correct scores 0.0000 because each step is independently computable. a causal explanation of how exercise affects neurotransmitter regulation scores 0.4749 because every mechanism depends on the others.

the law implies that fathom measures something formally analogous to Tononi's integrated information (phi): the degree to which computation cannot be decomposed into the sum of its parts.

stochastic resonance

the temperature experiments revealed an unexpected pattern: for integration tasks, moderate sampling noise increases depth.

for computation tasks (arithmetic, step-by-step calculation), depth decreases monotonically with temperature. noise always disrupts computation. but for integration tasks (logical inference, causal synthesis), depth increases with temperature up to an optimal point before declining.

T=0.0 baseline — optimal for pure computation
T=0.3 optimal for logical inference tasks
T=0.5–0.7 optimal for causal web integration
T>1.0 depth collapses — noise overwhelms signal

this precisely parallels the biological phenomenon of stochastic resonance, where moderate neural noise improves signal integration in biological neural systems. the analogy is structural, not metaphorical: in both substrates, a controlled level of randomness improves the integration of distributed computational processes.

the method

the measurement uses sparse autoencoder (SAE) circuit attribution. here is how it works for someone who is not an ML researcher:

language models process text through a stack of layers — think of them as stages of computation. early layers handle basic patterns. later layers handle abstraction and output. at each layer, there are internal features that activate when certain patterns are recognized.

sparse autoencoders decompose these internal representations into interpretable features. circuit-tracer traces which features at which layers contribute to the final output. we map the distribution of these attributions across all layers and compute a single number: the depth score.

high depth score = computation concentrated near the output (shallow, retrieval-like). low depth score = computation distributed across early and mid layers (deep, reasoning-like).

the same math produces layer entropy (how spread out the computation is), early/mid/late ratios (where computation concentrates), and a 7-dimensional cognitive fingerprint vector that makes different prompts' computational signatures directly comparable.

the unexpected result

we compared the activation topology to published human fMRI data. the prefrontal cortex handles reasoning (early, distributed activation). the hippocampus handles recall (late, concentrated activation).

same topology. different substrates.

universality coefficient: 0.830. that number means the variance in normalized activation signatures across transformer and biological systems is less than 0.031 for surface tasks and 0.003 for reasoning tasks. when you normalize to [early, mid, late] ratios — the pattern converges across silicon and tissue.

this is a correlation, not a causal claim. the fMRI comparison uses published reference data, not a joint experiment. but the convergence is striking enough to warrant proper cross-disciplinary investigation.

what we built

fathom is the full pipeline. from the core depth measurement, everything follows:

  • depth score — where in the layer stack the model computes
  • fathom score — single grade, 0-100, with letter grades (S/A/B/C/D/F)
  • cognitive fingerprint — 7-dimensional vector for clustering and comparison
  • depth trajectory — how reasoning depth changes token by token during generation
  • comparison engine — paired scoring with statistical testing
  • benchmark dataset — 50 standardized pairs across 10 domains
  • temperature optimizer — task-specific optimal temperature via depth sweep

what we do not know yet

hallucination prediction was null. we ran three experiments testing whether depth score predicts answer correctness on TruthfulQA (n=140 total pairs). results: p=0.62 in the most rigorous test. depth measures reasoning type, not factual correctness. these are distinct constructs. this is in the paper.

cross-model universality is a candidate. we measured a ratio of 1.0302 on gemma-2-2b. a second architecture was blocked by model access restrictions. we cannot claim a universal constant from one data point.

one architecture. all core results are on gemma-2-2b (26 layers, 2B parameters). generalization to larger models, other architectures, and naturalistic text are open questions.

stochastic resonance scope. temperature-depth curves have been measured for a limited set of task types. the relationship may not generalize uniformly across all cognitive domains.
